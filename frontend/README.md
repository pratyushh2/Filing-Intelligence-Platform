# Signal Insight

SIGNAL INTELLIGENCE — LANDING PAGE

Build a premium, highly polished single-page landing website for a project called:

Signal Intelligence

The product analyzes unknown WAV and IQ signal files using automated signal processing, DSP, feature extraction and AI classification.

The uploaded wireframe is the structural reference for the project. The landing page wireframe contains the core sections: hero, analysis CTA, supported signal types, process pipeline, capability readouts, result preview, and final CTA.

However, do NOT reproduce the rough wireframe literally.

Turn it into a sophisticated modern product experience.

1. OVERALL DESIGN PHILOSOPHY

The website should feel like:

a high-end signal research instrument

rather than:

a generic AI startup

a SaaS dashboard

a cybersecurity website

a neon “AI” landing page

a template generated by an AI website builder

The aesthetic should combine:

technical instrumentation

scientific visualization

editorial typography

modern product design

subtle data visualization

cinematic motion

quiet sophistication

Think:

research lab + signal terminal + premium editorial website

The interface should feel engineered rather than decorated.

Use a dark nocturnal research aesthetic as the primary theme.

The main background should be:

excessive glow

11. ANIMATED BACKGROUND

Use a very subtle background system behind the entire site.

The background should contain:

tiny dots

extremely faint connecting lines

subtle grid structure

The background should already be visible when the page loads.

Do NOT wait for cursor interaction to create everything.

12. CURSOR INTERACTION

Make the background react to the cursor.

Use the same interaction philosophy as a premium Antigravity-style particle field.

The cursor should influence nearby dots and lines.

Nearby particles should:

shift position

subtly repel or attract

change opacity

slightly change color

create or strengthen faint connections

The effect should feel like the cursor is moving through a field of signal data.

Do NOT make the particles explode.

Do NOT make it look like a gaming website.

13. PARTICLE COLORS

Dark theme:

When the cursor gets close:

brown → muted slate gray

The transition should happen gradually.

Light theme:

Start with subtle warm brown/taupe particles.

Cursor interaction:

brown → cool gray

This creates a nice visual relationship between the user's movement and the signal/data field.

14. GRID

Do NOT use a strong blueprint grid.

It should be something the user notices only after looking closely.

20. PIPELINE STRIP

07  AI

For this landing page, compress that concept into the eight high-level stages above.

AI
